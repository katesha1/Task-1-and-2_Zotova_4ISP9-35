# Task-1-and-2_Zotova_4ISP9-35
Реляционная БД учебно-лабораторного оборудования по Приказу №838 (2024)
Работу выполнила Зотова Екатерина 4ИСП9-35 в рамках производственной прктики.

Первой поставленной задачей было изучение Приказа Минпросвещения РФ от 28 ноября 2024 г N 838. После чего сформировать реляционную базу данных УЧЕБНО-ЛАБОРАТОРНОГО оборудования.
Формируя базу оборудования создала максимальное количество полей, объединяющего различные виды оборудования по назначению, функциональным особенностям, требованиям к инфраструктуре и т.п.

Источник: https://sh10-orlovka-r26.gosuslugi.ru/netcat_files/32/315/Prikaz_Minprosvescheniya_Rossii_ot_28.11.2024_N_838.pdf

Структура базы данных (SQL Server)

 `SubjectAreas` — предметные области
 `EquipmentTypes` — типы оборудования
 `InfrastructureRequirements` — требования к инфраструктуре
 `RegulatoryDocuments` — нормативные документы
 `LabEquipment` — основная таблица оборудования
 `EquipmentInfrastructure` — связь "многие-ко-многим"
 `EquipmentRegulations` — связь оборудования с нормативами

Работа выполнена в SQL Server Management Studio 22.
